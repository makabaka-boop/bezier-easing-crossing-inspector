# Easing 曲线编辑器（离线）

Lit + TypeScript 实现的多段三次贝塞尔缓动曲线编辑器，由 Compose 的 `easing` 服务提供页面。

## 模型

- 2～20 个关键帧，时间为**严格递增的整数**，值为任意实数。
- 相邻关键帧构成一段，每段两个控制点：`x ∈ [0,1]`，`y ∈ [-2,2]`（y 可越过端点 → 回摆/超调）。
- 段内按标准三次贝塞尔参数化（`u ∈ [0,1]`）：
  - `x(u) = 3(1-u)²u·cx1 + 3(1-u)u²·cx2 + u³`（cx∈[0,1] ⇒ 单调）
  - `y(u) = 3(1-u)²u·cy1 + 3(1-u)u²·cy2 + u³`，再线性映射到两端数值。

## 求值与反查（`easing/src/easing-core.ts`）

- **求值**：给定时间 t，先对单调的 `x(u)` 二分反解出 u，再算 `y(u)` 映射值。
- **阈值反查**：给定阈值，按 `y'(u)` 的零点（解析求解二次方程）把每段切成单调片，
  在每片上二分求根；穿越与**水平切触**都会命中。端点值相等 ⇒ 整段恒等，
  若等于阈值则返回**时间区间**而不是无穷多个点。结果去重、排序，误差 ≤ 1e-6。
- **一致性**：画布渲染、游标读数、导出数据全部经由 `CurveStore.evaluate` 同一求值路径；
  阈值反查按 revision 缓存，任何编辑都会 bump revision 并清空缓存——旧的反查结果立即失效。

## 开发

```bash
cd easing
npm install
npm run test     # Vitest：端点 / 水平切触 / 超调三交点 / 不同帧间距 / 恒等区间 / 缓存失效
npm run dev      # 本地开发服务器
npm run build    # 类型检查 + 产物构建（dist/）
```

## 运行（Compose）

```bash
docker compose up --build
# 打开 http://localhost:8080
```

`easing` 服务：多阶段构建（node 构建 → nginx 托管静态产物），完全离线可用。

## 编辑器操作

- 拖动关键帧（时间吸附整数、保持严格递增）与紫色控制柄（x∈[0,1]，y∈[-2,2]）。
- 拖动绿色游标线查看 `(t, v)`；拖动橙色阈值线查看穿越时刻/恒等区间。
- 双击空白处在曲线上插入关键帧；Alt+点击关键帧删除（保留 ≥2 个，上限 20）。
- 右侧面板可精确输入数值；“生成 JSON / 下载”导出 spec、游标、阈值解与 201 个采样点。
